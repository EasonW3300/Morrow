# 传输安全默认私有网络（Tailscale）优先

Morrow 是单主人自用系统，Runtime 直接暴露公网只会增加攻击面和证书/防火墙运维负担。决定：默认部署模式为所有设备与服务器加入同一私有网络（推荐 Tailscale，兼容任意 WireGuard 组网），Runtime 仅监听私有网络接口，传输安全由隧道层保证；设备间仍执行配对码 + 设备公钥指纹确认，防同网段内伪造。公网模式（Runtime 内嵌 ACME 自动证书 + 域名）作为可选能力预留，首版不验收。

## Considered Options

- 公网 VPS + Caddy 反向代理 + 域名证书：可行，但要求用户持续维护域名、证书与防火墙，与"Ubuntu 一键部署"目标冲突。

## Consequences

用户需安装 Tailscale（或同协议组网）并登录同一账号；没有公网直连能力，远程访问依赖 VPN 在线；ADR-0003 的单二进制部署不内嵌证书管理复杂度。
